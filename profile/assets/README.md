# Nudgeon organization assets

- `nudgeon-mark.svg` — square pigeon and signal mark for the GitHub organization avatar.
- `nudgeon-lockup.svg` — organization profile hero lockup.
- `nudgeon-flow.svg` — compact product flow used in the profile README.
- `nudgeon-avatar.png` — 1024 px raster export for GitHub organization settings.
- `nudgeon-lockup.png` — 1600 px raster preview of the hero lockup.
- `nudgeon-flow.png` — stable raster export used by the profile README.

The pigeon represents message delivery. The forward body and signal pulse distinguish it from a generic social bird, while the raised wing keeps the earlier transmission idea.

Brand colors:

- Deep navy: `#071827`
- Signal teal: `#55D8E6`
- Ocean blue: `#168AAD`
- Journey blue: `#4E7BFF`
- Delivery accent: `#B9F36B`
